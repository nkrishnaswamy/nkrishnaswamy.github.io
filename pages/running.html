I was not an athletic child. In 2015, to my surprise, I discovered I was actually pretty good at running, and I've been running marathons since shortly after I got my Ph.D. My near-term goals are to qualify for the Boston Marathon before I turn 35 (11:48 left to shave off my time and it's getting real close to my 35th birthday!), to run a marathon in every place that I've ever called home (4/7 down), and to run a half-marathon in every state in New England (4/6, but suddenly got harder after moving to Colorado). My longer-term goals are to run a marathon on every continent (2/7 complete) and run in all the World Marathon Majors (0/6 so far).

With frequent conference travel, I've been fortunate enough to be able to go for a run in some pretty cool places around the world. Below are videos of some of these runs, which I made by strapping a GoPro to my head. Sometimes the video gets pretty bouncy sped up like this, but it can be an interesting way to tour a new city.
