I was not an athletic child. In 2015, to my surprise, I discovered I was actually pretty good at running, and I've been running marathons since 2017, right after I got my Ph.D. My near-term goals are to qualify for the Boston Marathon before I turn 35 (13:35 left to shave off my time), and to run a marathon in every place that I've ever called home (3/7 down). My longer-term goals are to run a marathon on every continent (2/7 complete) and run in all the World Marathon Majors (0/6 so far).

With frequent conference travel, I've been fortunate enough to be able to run in some pretty cool places around the world. Below are videos of some of these runs, which I made by strapping a GoPro to my head. Sometimes the video gets pretty bouncy sped up like this way, but it can be an interesting way to tour a new city.
